# Vendored MediaRemote Adapter

This directory vendors `ungive/mediaremote-adapter` v0.7.6 at commit
`3ac3d4bdf862c7b5399b4fba4df5689f5c38609a`.

Upstream: <https://github.com/ungive/mediaremote-adapter>

The source is redistributed under the BSD 3-Clause license in `LICENSE`.
Weaver builds the framework from this source and invokes the adjacent
`mediaremote-adapter.pl` through `/usr/bin/perl`; it never resolves a Homebrew
installation path.
